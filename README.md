# 🧱 Brick Breaker - Juego en C# (Windows Forms)

Este es un proyecto de un juego tipo **Brick Breaker** desarrollado en **C# con Windows Forms**. El jugador controla una paleta para hacer rebotar una pelota y destruir bloques, ganando puntos y premios a medida que avanza.

## 🎮 Características

- 🎨 Interfaz gráfica hecha con Windows Forms
- 🔊 Efectos de sonido integrados
- 🖼️ Imágenes personalizadas para bloques, premios y fondo
- 🎯 Sistema de puntuación
- ❤️ Vidas limitadas (pierdes si se acaban)
- 🎁 Premios aleatorios al romper ciertos bloques
- 🧱 2 niveles con dificultad progresiva
- Tabla de puntuacion

## 🚀 Cómo jugar

1. Usa las teclas para mover la paleta.
2. Rebota la pelota contra los bloques para romperlos.
3. ¡Evita que la pelota caiga! Pierdes una vida si eso ocurre.
4. Avanza al siguiente nivel al destruir cierta cantidad de bloques.
5. Recolecta premios para mejorar tu juego.

## 🛠️ Tecnologías usadas

- Lenguaje: C#
- Plataforma: .NET Framework
- Entorno: Visual Studio
- Interfaz: Windows Forms
- Recursos multimedia: imágenes y sonidos integrados en el proyecto
